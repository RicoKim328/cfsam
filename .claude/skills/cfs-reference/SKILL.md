# cFS reference lookup

The bundle at `../` (relative to the cfsam repo root; from a worktree it is
`../../../..`) is the source of truth: branch `dev` @ `d2f1477`. It is
read-only. Read with Read/Grep/`git -C <bundle> log|show`; never edit, build in,
or change its checkout. A PreToolUse hook blocks writes.

Default variant: `SIMULATION=native`, EDS off (`CFE_EDS_ENABLED` unset).

## Where things are

| Fact | Location in the bundle |
|---|---|
| Mission name, spacecraft ID | `sample_defs/targets.cmake` (`MISSION_NAME`, `SPACECRAFT_ID`) |
| Apps built for every CPU | `targets.cmake` `MISSION_GLOBAL_APPLIST` (sbn* only when native and not EDS) |
| CPUs and per-CPU apps | `targets.cmake` `MISSION_CPUNAMES`, `<cpu>_APPLIST`, `<cpu>_PROCESSORID` |
| Startup script contents | generated by `sample_defs/generate_startup.cmake` (fixed lines + `CFS_APP_STARTUP_ORDER`), called from `sample_defs/<cpu>/install_custom.cmake:48` with `<cpu>_APPLIST`; written to `<cpu>/cf/cfe_es_startup.scr` under the install prefix only at install time (`INSTALL_SUBDIR` defaults to `cf`, `cfe/cmake/arch_build.cmake:791`) |
| Startup line fields | comments in `generate_startup.cmake`: type, file, entry point, name, priority, stack, load addr, exception action |
| App topic IDs | `apps/<app>/fsw/inc/<app>_topicids.h` (`DEFAULT_<APP>_MISSION_<X>_TOPICID`) |
| Topic ID → MID macros | `apps/<app>/config/default_<app>_msgid_values.h`, MID names in `default_<app>_msgids.h` |
| CMD/TLM MID bases | `sample_defs/inc/global_core_api_base_msgid_values.h`, per-CPU `sample_defs/<cpu>/cfe_core_api_base_msgid_values.h` |
| Mapping formula | `cfe/modules/core_api/config/default_cfe_core_api_msgid_mapping.h` (`MIDV = base | topic`) |
| EDS variant | `sample_defs/eds/`, `apps/<app>/config/eds_*` (out of scope by default) |

Config headers are selected by `generate_config_includefile`
(`cfe/cmake/global_functions.cmake:239`): a matching file in the mission defs
directory (optionally with a CPU/arch prefix) wins, and the app's `default_*`
file is only the fallback. Check `sample_defs/` for overrides before using a
default.

## Rules

- Cite every fact as `bundle/path:line` (bundle-relative) in code comments,
  tests, or reports.
- For non-trivial claims, delegate to the `cfs-fact-checker` agent.
- To test against bundle files, copy them unmodified into
  `tests/fixtures/cfs_<name>/` at their bundle-relative path and list them in
  that fixture's `SOURCE.md`.
